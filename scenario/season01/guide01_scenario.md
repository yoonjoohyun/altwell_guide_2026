제작 기준
원본의 7개 강의 단락을 Scene 01~07 및 scene01.mp4~scene07.mp4에 각각 1:1 대응한다. 시리즈명·진입 파일명은 가칭이다.
각 script 블록은 제공된 내레이션 본문을 그대로 수록했다. 붙여넣기로 끊긴 줄만 연결했으며, 단어·문장·순서와 원문의 표기를 수정하지 않는다. 제목은 음성 본문에 임의로 추가하지 않는다.
원문의 ‘3개월분을’, ‘그 매월’, ‘가격으로으로’와 6·7번 제목의 특수문자도 원문 보존 대상으로 유지한다. 녹음용 원고 정정은 이 시나리오의 범위에 포함하지 않는다. 화면 표시 문구는 별도로 요약한다.
내레이션이 전달의 중심이다. 좌측은 관계·수량·변화를 보여 주고, 우측은 같은 시점의 핵심을 짧게 정리한다. 내레이션 전체를 패널에 복사하지 않는다.
아래 초 단위 시간은 음성 없는 상태의 배치 초안이며 확정 싱크가 아니다. 각 이벤트의 [기준 음성]을 우선하여 실제 mp4의 해당 구절 시작 시각에 맞춘다. @duration auto는 총길이 반영용이며 문장별 자동 싱크를 의미하지 않는다.
[기준 음성], [연출], [패널 전환]은 개발자용 설명이며 실행 API나 화면 문구가 아니다. show/animate 등 기본 구문 외의 자연어 연출은 기존 모션 컴포넌트로 구현하며, 필요한 공통 모션만 추가한다.
기존 오토십·BASE·추천보너스·멤버 에셋은 HTML·CSS 컴포넌트를 재사용한다. PNG 배지로 대체하거나 기존 디자인을 변경하지 않는다.
달력, 가격 카드, 품목 카드, 결제·배송 도식, EP 카드, 체크·불가 표시, 요약 카드는 배지형 신규 에셋이 아닌 보조 HTML/CSS 오브젝트로 제작한다. 연결선은 SVG를 사용한다. 아래 보조 오브젝트 ID는 신규 제작 대상이며, 이미 등록된 asset 키로 간주하지 않는다.
상품명·상품 이미지는 제공되지 않았으므로 품목 A~E와 단순 상품 실루엣을 사용한다. 반드시 ‘구독 방식 예시’로 표시해 실제 대상 상품 목록으로 오인하지 않게 한다.
좌측 4:3 프레임, 우측 패널, 고정 배경, 상·하단 컨트롤러 구조를 유지한다. 씬별 DOM은 #motion-canvas 내부에만 만든다.
우측 제목은 씬 동안 유지한다. desc는 1~2문장, bullets는 한 번에 최대 3개를 기본으로 한다. 메시지가 바뀌면 이전 내용을 약 0.2초 페이드아웃하고 다음 내용을 약 0.3초로 교체한다.
모션은 등장 0.35~0.5초, 이동·변환 0.5~0.7초, 강조 1회를 기본으로 한다. 수치·규칙 설명 중에는 반복 플로팅을 멈춰 읽기 쉽게 한다. 할인·EP·추천포인트를 동일한 색이나 같은 토큰으로 표현하지 않는다.
BASE사업자 자격과 지위는 독립적으로 표현한다. 오토십만으로 BASE가 완성되거나 BASE 배지가 P 지위로 바뀌는 연출은 하지 않는다.
종료 페이드는 마지막 의미 단위의 낭독이 끝난 뒤에 실행한다. 음성 말미에 여유가 없다면 @END 기준 페이드를 뒤로 조정하거나 생략하여 문장이 끝나기 전에 화면을 지우지 않는다.
